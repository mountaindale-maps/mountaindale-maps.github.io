    Cable lengths are approximate, measured along the drawn route, in feet.

    About measurements

    Stored lengths stay metres (feet × 0.3048). Horizontal distance is the WGS84 geodesic along the cable, including each bend. Grid UTM length is separate. A vertical pole drop is added to that horizontal length. Only an explicit slope rise is combined as a hypotenuse. Slack and service loops are added after that. The sampled image transform is validated. This is not a survey and it does not state a ground-error bound.
